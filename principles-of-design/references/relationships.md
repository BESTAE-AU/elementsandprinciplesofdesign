# Principle Relationships and Element Links

## Relationship to the 12 Elements of Design

Claude should identify only meaningful relationships rather than artificially connecting every Element to every Principle.

Use the following prompts when analysing:

| Element | Principle-focused questions |
|---|---|
| Line | Does line connect, divide, repeat, direct, align or create tension? |
| Direction | Does orientation guide movement, oppose another direction or establish flow? |
| Shape | Are shapes repeated, contrasted, grouped, proportioned or used as focal devices? |
| Form | How do volumes relate, balance, repeat or establish hierarchy? |
| Space | How do proximity, isolation, density and negative space affect grouping or emphasis? |
| Size and Scale | How do size relationships influence visual weight, proportion, hierarchy or emphasis? |
| Time and Duration | How do timing, sequence and duration affect rhythm, emphasis, contrast or movement? |
| Value | How does tonal difference affect contrast, hierarchy, depth or emphasis? |
| Colour | How do colour similarity and difference affect harmony, contrast, unity, hierarchy or recognition? |
| Texture | Does texture create variation, contrast, material unity or focal emphasis? |
| Typography | How do type size, weight, style, spacing and position affect hierarchy, contrast, unity and rhythm? |
| Layout and Composition | How are relationships structured across the whole design? |

Claude should state the **specific variable manipulated**, not merely name the Element.

## Relationships Between Principles

Claude should distinguish related Principles rather than treating them as synonyms.

| Relationship | Distinction |
|---|---|
| Unity vs Harmony | Unity concerns whole-system coherence; harmony concerns compatibility between parts. |
| Balance vs Symmetry | Symmetry is one method of achieving balance. |
| Hierarchy vs Emphasis | Hierarchy creates levels of priority; emphasis creates focal prominence. |
| Contrast vs Emphasis | Contrast is difference; emphasis is prominence that may result from difference. |
| Repetition vs Pattern | Repetition is recurrence; pattern is organised recurrence. |
| Repetition vs Rhythm | Repetition provides recurring material; rhythm is the cadence created through recurrence, interval and variation. |
| Direction vs Movement | Direction is orientation/pathway; movement is progression through space or time. |
| Variety vs Contrast | Variety introduces difference across a system; contrast describes perceptible difference between specific conditions. |
| Unity vs Repetition | Repetition may support unity, but unity can also arise through other relationships. |
| Tension vs Imbalance | Imbalance may create tension, but tension can also arise through spacing, opposition, cropping or disruption. |
| Proportion vs Scale | Proportion concerns relationships among parts; scale concerns size relative to a reference or context. |
| Alignment vs Proximity | Alignment creates positional relationships; proximity creates spatial grouping. |

## Interaction Between Multiple Principles

Claude should actively explain multi-Principle relationships when relevant.

Examples:

**Contrast → Emphasis → Hierarchy**

**Repetition → Rhythm → Unity**

**Alignment + Proximity → Grouping → Hierarchy**

**Variety + Repetition → Rhythm while retaining Unity**

**Asymmetry + Contrast → Tension + Movement**

**Proportion + Contrast → Emphasis → Hierarchy**

**Pattern interruption → Contrast → Emphasis**

The arrows represent possible causal relationships, not universal laws.
