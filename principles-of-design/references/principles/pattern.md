# Pattern

## Definition

Pattern is an organised system of repeated elements or relationships that produces a recognisable visual, structural or temporal arrangement.

## Core logic

Pattern requires recurrence **plus organisation**.

## Forms

- regular
- alternating
- modular
- geometric
- organic
- tessellated
- directional
- progressive
- randomised within constraints
- temporal

## Elements

Shape, line, colour, value, texture, space and time are particularly important.

## Relationships

- repetition is a foundation for pattern
- pattern can create rhythm
- pattern can strengthen unity
- variation can interrupt pattern
- a pattern break can create emphasis

## Applications

Textiles: repeat design, placement prints, engineered patterns.  
Branding: proprietary graphic systems.  
Packaging: surface identity.  
Architecture: façade modules, screens and structure.  
UI: repeated layout modules and content structures.  
Motion: looping patterns and repeated behaviours.

## Accessibility

Dense patterns may interfere with text readability or create visual discomfort. Moving repetitive patterns may affect motion-sensitive users.

## Trade-offs

- recognition ↔ visual dominance
- decorative richness ↔ clutter
- consistency ↔ monotony
- dense repetition ↔ legibility issues

## Misconception

**Misconception:** Any repeated element is a pattern.  
**Correction:** Pattern involves organised recurrence.
