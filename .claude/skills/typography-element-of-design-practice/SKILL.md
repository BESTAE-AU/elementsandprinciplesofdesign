# Typography: applying it in a design

This skill handles **applying it in a design** for typography as an element of design. Everything known about typography (definition, variables, types, relationships with the other elements and the principles, fields, production, misconceptions and worked examples) is in `references/element-knowledge.md`. The shared method is in `references/design-method.md`. Read the sections the workflow points to.

Related skills: `typography-element-of-design-teaching`, `typography-element-of-design-feedback`, `typography-element-of-design-analysis`; `typography-element-of-design` for general questions about typography; the `*-principle-of-design` skills for principles.

## Workflow

1. **Clarify the brief.** Get the audience, purpose, every output or touchpoint, the production methods and any fixed constraints (brand rules, budget, equipment).
2. **Name the design question** before changing anything, e.g. "which weight keeps the mark readable at 16 px and in embroidery?". Don't vary things at random (method §7).
3. **Pick one variable** from the table below and propose three clearly different options. Hold the rest constant.
4. **Test in real conditions:** real size, real medium, real viewing distance or device. Check the production table below.
5. **If it's a brand,** extend the surviving options to at least three touchpoints and record what breaks away from the logo (method §8).
6. **Decide and record** the result as a rule (e.g. minimum sizes, permitted variants) and as a sophisticated justification: evidence → alternative rejected → trade-off accepted (method §4).

## Variables

| Variable | Range | Typical effect | Watch for |
|---|---|---|---|
| **Typeface / family** | serif, sans, slab, script, display, mono, variable | voice, recognition, function | Avoid personality stereotypes; check language support |
| **Weight** | thin → black | hierarchy, emphasis | Very light weights fail small |
| **Width** | condensed → extended | fit, texture | Condensed text can hurt readability |
| **Style** | roman, italic, oblique | emphasis, voice | Use emphasis sparingly and meaningfully |
| **Size** | display, body, caption, label | hierarchy, readability | Relate to viewing distance and device |
| **Case** | upper, lower, sentence, title | word shape, tone | All caps slows long passages |
| **Kerning / tracking** | tight ↔ loose | rhythm, recognition | Optically check logos and headlines |
| **Leading** | tight ↔ open | readability, density | Relate to size, line length and script |
| **Line length** | short ↔ long measure | reading comfort | Adapt for responsive layouts |
| **Alignment** | left, right, centred, justified | reading flow, texture | Justified text can create rivers |
| **Colour / value** | text-to-background contrast | hierarchy, accessibility | Meet contrast requirements |

## Production and reproduction

| Process | Typography risks |
|---|---|
| Print | Fine serifs, knockouts and small text need proofing; stock and ink spread affect clarity |
| Screen | Rendering and pixel density affect small text |
| Web | Licensing, loading, variable-font support and fallbacks |
| Embroidery / vinyl | Simplify fine counters and strokes; test minimum letter size |
| Motion | Reading time and compression affect title and caption legibility |

## Typography across fields

- **Branding:** specify typography as a system — wordmark construction, primary and secondary typefaces, hierarchy, weights, spacing, case, numerals, language support, fallback fonts, licensing, motion behaviour and examples. Consistency is typographic behaviour, not just a repeated font.
- **Graphic and communication design:** hierarchy, readability and voice in posters, publications, packaging and infographics.
- **Film, video and animation:** titles, lower thirds, captions, subtitles and kinetic type must allow for safe areas, reading time, motion, contrast and platform cropping.
- **UI / UX:** responsive type scales, labels, forms, navigation and error messages need readable sizes, line lengths and hierarchy. Plan for font loading, fallbacks, localisation and user zoom.
- **Textiles and fashion:** type printed, embroidered, woven, appliquéd or cut; counters, stroke widths and spacing must suit the process.
- **Product and industrial design:** labels, control legends, warnings and packaging text must stay legible in real conditions and within production limits.
- **Interiors and architecture:** signage and environmental type depend on viewing distance, contrast, mounting, lighting and navigation.
- **Technical communication:** conventions for dimensions, labels and annotation; clarity and consistency come first.
