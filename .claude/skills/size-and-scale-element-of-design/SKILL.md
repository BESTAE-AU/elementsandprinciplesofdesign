# Size and scale — element of design

This skill gives Claude the size-and-scale-specific knowledge for teaching, analysing and designing with size and scale. The shared method — analysis progression, justification levels, Factors Affecting Design, experimentation, differentiation, feedback approach and language rules — is in `references/design-method.md`. Read the relevant section of that file when a task calls for it.

The core habit: always name the **reference** — bigger or smaller than *what*? Move from **dimensions and relationships** → **effect** (hierarchy, depth, usability, drama) → **why that matters here** → **how well it works and what it costs**.

## What size and scale are

**Size** is the measurable or perceived dimensions of an element or object. **Scale** is size relative to a reference: the user, the environment, surrounding elements, the original object or the output format. **Proportion** describes the ratios within or between parts.

Keep them distinct — students use them interchangeably:
- **Size can be absolute** (120 mm, 48 px); **scale is relational** (twice the headline, human scale, 1:50).
- **A logo can keep its proportions while changing size,** and its perceived scale still changes relative to the page or screen.
- **Visual size vs interactive size:** in UI, the visible icon and its touch target are different sizes.

## Variables

| Variable | Range | Typical effect | Watch for |
|---|---|---|---|
| **Absolute size** | physical or pixel dimensions | fit, legibility, manufacture | Specify units and tolerance |
| **Relative size** | larger or smaller than neighbours | hierarchy, comparison | Bigger isn't automatically more important |
| **Human scale** | relation to body, reach, vision | ergonomics, comfort | Use anthropometric and accessibility evidence |
| **Environmental scale** | relation to room, street, landscape | visibility, wayfinding, atmosphere | Viewing distance matters |
| **Scale contrast** | large beside small | emphasis, tension, drama | Can distort perceived importance |
| **Responsive scale** | fluid or breakpoint resizing | hierarchy across devices | Not everything should scale uniformly |
| **Minimum / maximum size** | limits for recognition or use | protects legibility and production | Test real outputs, not the design file |
| **Optical scaling** | deliberate redesign at different sizes | keeps appearance and recognition | Small versions need heavier strokes, less detail |

## Types

- **Physical size** — measurable dimensions; products, print, rooms.
- **Visual size** — perceived prominence in a composition; graphics, photography.
- **Relative scale** — size compared with another element; hierarchy, data visualisation.
- **Human scale** — size referenced to the body; products, furniture, spaces.
- **Monumental / miniature scale** — deliberately extreme relative to expectations; environmental graphics, art and design.
- **Responsive scale** — adapting across devices and contexts; UI, identity systems.
- **Drawing scale** — the ratio between drawing and object (1:1, 1:10, 1:100).

## How size and scale work with the other elements

- **Line:** stroke weight doesn't scale optically; thin lines vanish when reduced and heavy lines clog.
- **Direction:** a sequence from large to small reads as recession or movement into depth.
- **Shape:** detail inside a shape disappears at small sizes; small-size variants need simpler shapes and wider gaps.
- **Form:** the same form reads differently at hand, furniture and building scale; ergonomics fix many dimensions.
- **Space:** a small element with generous space round it can outrank a bigger crowded one; diminishing size builds implied depth.
- **Colour:** small areas of colour look less saturated and are harder to distinguish; large areas look more intense than the swatch.
- **Value:** small text needs stronger value contrast than large text to stay readable.
- **Texture:** texture scale changes its reading — fine grain becomes noise when reduced or a bold pattern when enlarged.
- **Typography:** type size sets hierarchy and readability; display and text sizes often need different typefaces or optical sizes.
- **Layout and composition:** scale relationships between headline, image and body set the hierarchy of the whole page.
- **Time and duration:** animated scale changes (zooms, grows) create emphasis and transitions but shouldn't replace real hierarchy.

## How size and scale contribute to the principles

- **Hierarchy:** the most direct link — relative size ranks information.
- **Emphasis:** scale contrast (one very large element) creates a focal point.
- **Proportion:** internal ratios (logo mark to wordmark, head to body in illustration, seat to table).
- **Balance:** one large element can balance several small ones.
- **Contrast and tension:** extreme scale differences create drama or surprise.
- **Rhythm:** a graduated sequence of sizes creates progression.
- **Unity:** a consistent type scale or spacing scale ties a system together.
- **Movement:** shrinking sizes suggest travel into depth; growing sizes suggest approach.

## Size and scale across fields

- **Branding:** identities need scalable logos, responsive variants, minimum sizes, optical corrections, and favicon and avatar adaptations. Test on packaging, signage, social avatars, mobile headers, merchandise and large environmental uses.
- **Graphic and communication design:** type scales, image-to-text ratios, poster viewing distance and data visualisation (areas and lengths must be proportional to values).
- **Photography, film and animation:** shot size (extreme wide to extreme close-up) changes subject scale in the frame and so what's emphasised. Animated scale changes need reduced-motion alternatives.
- **UI / UX:** text size, icon size, touch-target size and component scale affect accessibility. Responsive systems should keep hierarchy, not just shrink everything.
- **Textiles and fashion:** motif scale changes how a print reads across a garment; feature scale affects proportion; pattern scale affects yield and matching.
- **Product and industrial design:** dimensions interact with anthropometrics, grip, portability, storage and tolerance. Smaller can save material but hurt usability or repair.
- **Interiors and architecture:** furniture, openings, signage and volumes must suit human and environmental scale. Signage size depends on viewing distance.
- **Technical communication:** drawings use stated scales (1:1, 1:10, 1:100). Scaling a drawing doesn't change the object; dimensions stay authoritative.

## Production and reproduction

| Process | Size and scale risks |
|---|---|
| Print and logo reproduction | Set minimum sizes from real proofs and printer specifications |
| Raster images | Enlarging reveals too-low resolution |
| Embroidery / cutting | Tiny details and gaps become unmakeable |
| Products | Tolerance and tool resolution set minimum features and wall thickness |
| UI | Text and control sizes must meet accessibility guidance (e.g. WCAG) |

## Common misconceptions

| Misconception | Better understanding |
|---|---|
| "Size and scale are the same." | Scale is relational; name the reference. |
| "A logo scales proportionally forever." | Small uses often need simplified or optically adjusted versions. |
| "Bigger always means more important." | Size contributes to hierarchy, but so do placement, contrast and space. |
| "If it looks right on my screen, it's the right size." | Screen zoom hides real size. Print or view at actual size and distance. |
| "Scaling a drawing changes the object." | The scale changes the representation; dimensions stay true. |

## Worked analysis (model for exemplars and annotations)

Scenario: a public-health poster for a bus shelter. A single enormous water droplet fills the top two-thirds; beneath it, a small person holds an umbrella under the drop. The headline "Every drop counts" sits at the bottom at 90 mm cap height.

- **Identify:** "The poster uses scale."
- **Describe:** "The droplet is about 1.2 m tall on a 1.8 m poster; the person is about 150 mm tall. The headline has a 90 mm cap height."
- **Explain:** "The extreme scale contrast between drop and person makes the drop the focal point and turns a small thing — one drop — into something huge, which dramatises the message."
- **Analyse:** "Scale works with space and hierarchy: the drop's size and the empty background around it make it read first; the person gives a human-scale reference, so viewers understand the drop is 'too big'. The headline is small relative to the image but large for its viewing distance."
- **Evaluate:** "Effective for a bus shelter, where people see it from 3–10 m and the image reads instantly. However, 90 mm type may be the minimum readable from the road side of the shelter; a viewing-distance test would confirm whether the headline needs to grow at the expense of the drop."

Each level should add a link in the chain, not simply more words.

## Justification examples (Year 11 band logo)

- **Weak:** "I made the logo big so people see it."
- **Developing:** "I made the band name larger than the symbol so the name stands out."
- **Strong:** "I set the band name at twice the symbol's height, so fans recognise the name first on posters, and created a symbol-only version for places where the name won't fit, like the Instagram avatar."
- **Sophisticated:** "I tested the full logo at 1200 px, 180 px and 32 px. At 32 px the name was unreadable and the symbol's fine strings disappeared, so I made a simplified symbol-only mark with thicker strings for anything under 64 px. The full logo is used above that. I lost some detail at small sizes but kept the band recognisable everywhere it appears."

## Feedback patterns to look for in student work

- **Size and scale used interchangeably** with no reference named.
- **"Big = important"** with no discussion of placement, space or contrast.
- **Everything the same size** — flat hierarchy.
- **Never tested at real size** — screen zoom trusted.
- **One logo size for every use** — no small-size or large-size variant.
- **Product dimensions without human reference** (hand size, reach, seat height).

## Activity ideas for teaching resources

- **Hierarchy by size only:** set the same event details at three different size hierarchies; ask peers which reads first.
- **Minimum size test:** print a logo at 100, 50, 25 and 10 mm; record where it fails.
- **Shot size sort (Multimedia):** sort film stills from extreme wide to extreme close-up; discuss what each emphasises.
- **Human-scale audit (D&T):** measure classmates' hand spans and design a handle range from the data.
- **Scale drawing (Graphics):** draw the same object at 1:1, 1:2 and 2:1; label the scale correctly.
- **Motif scale (Textiles):** print one motif at three scales on the same garment template; compare the effect.
