# Size and scale: feedback and marking

Use this file when a teacher shares student work or a justification and wants feedback, a mark or "what gets them to the top band" on size and scale.

## Workflow

1. **Read the work against its brief.** Note the audience, purpose and every touchpoint or output named (cups, embroidery, a phone screen, signage…). Reproduction problems usually hide there.
2. **Start from what the student actually did.** Quote their words or point to the part of the design, and name the size and scale variable involved (Variables in `SKILL.md`).
3. **Check for the patterns below** and the misconceptions in `knowledge.md`.
4. **Check production and accessibility.** Use the production table in `knowledge.md` and `method/checks-and-language.md`.
5. **Place the reasoning on the justification ladder** (weak → developing → strong → sophisticated; `method/justification.md`). Say which link in the chain is missing.
6. **If marking:** use the rubric supplied. If none is supplied, use `marking-rubric-builder` (if available) to generate NESA-aligned criteria first, mark against them and say they were generated. Without that skill, give feedback without a grade (`method/feedback.md`).
7. **Write it up:**
   - **What's working:** specific, not generic.
   - **What's holding it back:** 2–4 points, each quoting the student.
   - **Next steps:** one or two, phrased as tests or design decisions, in priority order.
   - **Model structure** (optional): a fill-in-the-blanks version of a top-level justification, with a note not to copy the numbers.
   - **Teacher notes:** current level, gap to the top, and a conferencing question.

Keep the tone warm, honest and specific.


## Feedback patterns to look for in student work

- **Size and scale used interchangeably** with no reference named.
- **"Big = important"** with no discussion of placement, space or contrast.
- **Everything the same size** — flat hierarchy.
- **Never tested at real size** — screen zoom trusted.
- **One logo size for every use** — no small-size or large-size variant.
- **Product dimensions without human reference** (hand size, reach, seat height).

## Justification examples (Year 11 band logo)

- **Weak:** "I made the logo big so people see it."
- **Developing:** "I made the band name larger than the symbol so the name stands out."
- **Strong:** "I set the band name at twice the symbol's height, so fans recognise the name first on posters, and created a symbol-only version for places where the name won't fit, like the Instagram avatar."
- **Sophisticated:** "I tested the full logo at 1200 px, 180 px and 32 px. At 32 px the name was unreadable and the symbol's fine strings disappeared, so I made a simplified symbol-only mark with thicker strings for anything under 64 px. The full logo is used above that. I lost some detail at small sizes but kept the band recognisable everywhere it appears."
