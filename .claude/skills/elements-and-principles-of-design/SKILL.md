# Elements and principles of design: overview

This skill is the map of the suite. Use it when a request covers several elements or principles at once. When the request narrows to one element, one principle or one job, switch to the specialist skill listed below. The shared method is in `references/design-method.md`.

## Elements vs principles

- **Elements** are the variables a designer manipulates: line, direction, shape, form, space, size and scale, time and duration, value, colour, texture, typography, and layout and composition. Typography and layout are broader systems than some traditional lists include. They're included here because they are central to visual, digital and multimedia practice.
- **Principles** are relationships and organisational effects that arise from how elements are used: balance, contrast, emphasis, hierarchy, movement, rhythm, repetition, pattern, proportion, unity, harmony, variety, alignment, proximity and tension.
- An element **contributes to** a principle; it isn't the principle. For example, "value contrast and scale create emphasis", not "the design uses emphasis colour".
- The 12 elements work as **one interacting system**. Analyse the element in focus through its relationships with the others.

## Planning across elements

When planning a unit or scope and sequence:
- **Start with elements that are easy to see and test** (line, shape, value, colour), then build to systems (space, typography, layout) and time-based elements (time and duration, direction in motion).
- **Introduce principles as relationships** once students can describe two or three elements. For example, teach contrast after value and colour, and hierarchy after size and space.
- **Revisit the same analysis progression** for every element so students transfer the thinking, not just the vocabulary (method §2 and §10).
- **End with a project** that requires controlled experimentation and a sophisticated justification (`design-experimentation`, `design-justification-writing`).

## Quick glossary

For an "elements and principles" glossary or revision sheet, define each term in one sentence. Give one example and one non-example, and pair each principle with the elements that most often create it. The "What each element contributes" section in every principle skill lists these pairings.
