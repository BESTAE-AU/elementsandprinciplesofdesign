## Elements vs principles

- **Elements** are the variables a designer changes: line, direction, shape, form, space, size and scale, time and duration, value, colour, texture, typography, and layout and composition.
- **Principles** are the relationships and effects that arise from how elements are used: balance, contrast, emphasis, hierarchy, movement, rhythm, repetition, pattern, proportion, unity, harmony, variety, alignment, proximity and tension.
- **An element contributes to a principle; it isn't the principle.** Say "value contrast and scale create emphasis", not "the design uses emphasis colour".
- **The elements work as one interacting system.** Analyse the element in focus through its relationships with the others.

## Planning across elements

When planning a unit or a scope and sequence:
- Start with elements that are easy to see and test (line, shape, value, colour), then build to systems (space, typography, layout) and time-based work.
- Introduce principles as relationships once students can describe two or three elements. For example, teach contrast after value and colour, and hierarchy after size and space.
- Reuse the same analysis progression for every element, so students transfer the thinking and not just the vocabulary.
- End with a project that needs controlled experimentation and a sophisticated justification.

For a glossary or revision sheet: give one sentence per term, one example and one non-example. Pair each principle with the elements that most often create it; every principle skill lists these.
