# Design method: Building teaching resources and differentiation

Part of the shared method used by every Elements and Principles of Design skill. The other parts sit alongside this file in `references/method/`.

## Building teaching resources

When producing a lesson, worksheet, workbooklet, Canvas page or scaffold, move learners through:

**knowledge → recognition → description → analysis → controlled experimentation → application → justification → evaluation → refinement**

Do not jump from a definition straight to "design your own". Keep resources **tight**, though: a single printed lesson should fit the lesson time without padding. Use one short modelled example rather than several, one stimulus to analyse (add a non-example only when the comparison is the point of the task), and cut anything a student won't actually write on or a teacher won't use. The answer key can be more generous than the student pages. In practice:

- Include examples **and non-examples**; comparison teaches faster than definition.
- Model a response before asking for one (worked example → guided → independent).
- Introduce vocabulary explicitly and reuse it.
- Connect to the student's own project where possible.
- Leave room for alternatives and testing, not just a single answer.
- Feedback prompts should point to the next design decision.

For a full workbooklet or unit, hand off to `content-booklet-builder`; for hands-on technique instruction, `practical-skill-builder`; for rubrics, `marking-rubric-builder`; for print layout, `workbooklet-style-system` — if those skills are available.

## Differentiation

Same concept, different scaffolding; do not simplify the concept into something inaccurate.

- **Support:** visual identification, controlled two-way comparisons, labelled examples, sentence starters, fewer variables, partly completed tables, word bank.
- **Core:** independent analysis, controlled experiments, justified selection, application in at least two contexts.
- **Extension:** competing constraints, cross-platform systems, audience interpretation, production limits, cultural critique, trade-off analysis, evaluating alternatives with evidence.
