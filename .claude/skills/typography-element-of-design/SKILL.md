## What typography is

Typography is the design and organisation of written language through typeface, style, size, spacing, alignment, hierarchy, composition and behaviour across media. It is both a visual element and a verbal communication system.

Keep the terms distinct:
- **Typeface vs font:** a typeface is the design family; a font is a specific style or digital file within it.
- **Kerning vs tracking vs leading:** kerning adjusts specific letter pairs; tracking adjusts spacing across a range; leading is the vertical space between lines.
- **Legibility vs readability:** legibility is recognising individual characters; readability is comfortably processing extended text.

## Variables

| Variable | Range | Typical effect | Watch for |
|---|---|---|---|
| **Typeface / family** | serif, sans, slab, script, display, mono, variable | voice, recognition, function | Avoid personality stereotypes; check language support |
| **Weight** | thin → black | hierarchy, emphasis | Very light weights fail small |
| **Width** | condensed → extended | fit, texture | Condensed text can hurt readability |
| **Style** | roman, italic, oblique | emphasis, voice | Use emphasis sparingly and meaningfully |
| **Size** | display, body, caption, label | hierarchy, readability | Relate to viewing distance and device |
| **Case** | upper, lower, sentence, title | word shape, tone | All caps slows long passages |
| **Kerning / tracking** | tight ↔ loose | rhythm, recognition | Optically check logos and headlines |
| **Leading** | tight ↔ open | readability, density | Relate to size, line length and script |
| **Line length** | short ↔ long measure | reading comfort | Adapt for responsive layouts |
| **Alignment** | left, right, centred, justified | reading flow, texture | Justified text can create rivers |
| **Colour / value** | text-to-background contrast | hierarchy, accessibility | Meet contrast requirements |
