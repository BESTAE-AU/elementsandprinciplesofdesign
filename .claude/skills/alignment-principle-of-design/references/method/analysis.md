# Design method: Analysis: reasoning chain, analysis progression, the four lenses and scaffolded questions

Part of the shared method used by every Elements and Principles of Design skill. The other parts sit alongside this file in `references/method/`.

## Reasoning chain

Treat every use of an element as a decision someone made. The chain Claude follows, whether teaching, analysing or designing:

**observable characteristic → perceptual or functional effect → what it communicates → purpose it serves → fit with audience and context → how well it works, and what it costs**

Skipping links is the most common weakness in student writing ("the lines make it look modern") and in AI-generated analysis. Each claim of effect should be traceable to something you could point at. Move from observable evidence to interpretation, never the reverse.

Keep five kinds of statement apart, because they need different levels of certainty:

- **observable characteristics** — can be pointed at or measured ("the rule is 0.25 pt");
- **common perceptual associations** — often true, never guaranteed ("diagonals *can* suggest movement");
- **culturally or contextually dependent interpretations** — true for some audiences ("in this market, red *may* signal luck");
- **functional consequences** — what it lets people do or stops them doing;
- **technical or measurable properties** — what governs reproduction and performance.

The 12 elements — line, direction, shape, form, space, size and scale, time and duration, value, colour, texture, typography, layout and composition — work as one interacting system. Analyse the element in focus, but through its relationships with the others. Don't force an element into a discipline where it doesn't meaningfully apply (time in a static textile, for example); say so briefly and move on.

## Analysis progression

NSW TAS command verbs build on each other. Use them in order and use them accurately.

1. **Identify** — name where the element is present (actual or implied).
2. **Describe** — state observable characteristics precisely, without interpretation: which variable, what value, where.
3. **Explain** — state the effect and the cause: *because* of this characteristic, this happens.
4. **Analyse** — show relationships: how the element works with other elements and principles, what would change if the variable changed.
   - *Connect to communication* — what it may communicate to the audience.
   - *Connect to purpose* — how it supports the intended function or message.
   - *Connect to audience and context* — why it may be appropriate here.
5. **Evaluate** — judge against the brief or explicit criteria, with evidence, and name what is gained and what is compromised.

Evaluation needs a criterion. "It works well" is not an evaluation; "it keeps the title legible at thumbnail size, which the social brief requires" is.

## Characteristics, features, properties, attributes

The Multimedia syllabus uses four lenses that students often blur. Keep them distinct:

| Lens | Question it answers | Example (any element) |
|---|---|---|
| **Characteristics** | What can be observed or perceived? | weight, direction, hue, spacing, duration |
| **Features** | What does this use of the element let the design do? | separate, group, lead, identify, signal state |
| **Properties** | What measurable or technical qualities govern its behaviour? | 0.25 pt stroke, 4.5:1 contrast, 300 ms, kerf 0.2 mm |
| **Attributes** | How does it relate to audience, purpose, context and meaning? | suits young readers; matches a craft brand; readable in a moving vehicle |

## Scaffolded questions

Use these as thinking prompts, adapted to the element:

- **Recognise:** Where is the element present, actual or implied? What type is it?
- **Describe:** Which characteristics can you name without interpreting? Which variable dominates?
- **Explain:** What effect does it have, and which characteristic causes it?
- **Analyse:** How does it interact with other elements and principles? What would change if you altered one variable?
- **Apply:** Which treatment best fits this brief, and what constraints shape it?
- **Justify:** What did you choose, what did you reject, and what evidence supports the choice?
- **Evaluate:** How well does it meet the criteria? Where does it perform differently across uses or users?
- **Refine:** What single change comes next, and what evidence points to it?
