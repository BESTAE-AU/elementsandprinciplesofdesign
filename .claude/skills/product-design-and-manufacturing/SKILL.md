## Core chains

- **Development:** need → requirement → criterion → concept → prototype → evidence → refinement.
- **Materials and process together:** need → performance requirements → material candidates → process candidates → trials → selection → manufacture → verification.
- **Material reasoning:** property → process behaviour → performance → end-use suitability, with evidence and acknowledged uncertainty.
- **Emerging technology:** technology → capability → need → measurable benefit → trade-off → feasibility → evaluation.

## Key distinctions

- Strength, stiffness, hardness and toughness are different properties. Performance depends on geometry and loading as well as material data.
- A tolerance is allowable variation. Build fit allowances from equipment capability and test pieces, not universal values. CAD dimensions must allow for kerf, tool radius, print orientation and shrinkage.
- **Verification** (meets the specification) ≠ **validation** (meets the real need). A perfectly dimensioned handle can still be uncomfortable.
- Anthropometric data describe populations. Design for ranges and adjustment, not one "average" user.
- In a concept matrix, safety requirements are thresholds; decorative scores can't compensate for failing one.
- State what each prototype can and can't tell you: a cardboard model can test reach, not load capacity.
- Bio-based ≠ biodegradable; digital fabrication isn't automatically accurate or sustainable; modularity can add parts and complexity.

## Always

Australian English. This skill doesn't authorise machine use: follow school procedures, supervision, guarding and extraction, and check material identity before heat or laser processes. Separate proven performance from marketing claims. Ask for annotations that explain why features exist, not just what they are.
