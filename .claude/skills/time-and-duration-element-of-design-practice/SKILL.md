# Time and duration: applying it in a design

This skill handles **applying it in a design** for time and duration as an element of design. Everything known about time and duration (definition, variables, types, relationships with the other elements and the principles, fields, production, misconceptions and worked examples) is in `references/element-knowledge.md`. The shared method is in `references/design-method.md`. Read the sections the workflow points to.

Related skills: `time-and-duration-element-of-design-teaching`, `time-and-duration-element-of-design-feedback`, `time-and-duration-element-of-design-analysis`; `time-and-duration-element-of-design` for general questions about time and duration; the `*-principle-of-design` skills for principles.

Apply the language rules in `references/design-method.md` §14: Australian English, describe before interpreting, conditional language for emotional or cultural associations, and name the criterion whenever something "works".

## Workflow

1. **Clarify the brief.** Get the audience, purpose, every output or touchpoint, the production methods and any fixed constraints (brand rules, budget, equipment).
2. **Name the design question** before changing anything, e.g. "which weight keeps the mark readable at 16 px and in embroidery?". Don't vary things at random (method §7).
3. **Pick one variable** from the table below and propose three clearly different options. Hold the rest constant.
4. **Test in real conditions:** real size, real medium, real viewing distance or device. Check the production table below.
5. **If it's a brand,** extend the surviving options to at least three touchpoints and record what breaks away from the logo (method §8).
6. **Decide and record** the result as a rule (e.g. minimum sizes, permitted variants) and as a sophisticated justification: evidence → alternative rejected → trade-off accepted (method §4).

## Variables

| Variable | Range | Typical effect | Watch for |
|---|---|---|---|
| **Duration** | short, long, fixed, user-controlled | comprehension, emphasis, dwell | Allow enough reading and processing time |
| **Timing** | early, late, synchronous, offset | causality, response, emphasis | Match timing to user action or story beat |
| **Sequence** | linear, branching, cyclical, layered | narrative and information structure | Order can change meaning |
| **Pacing** | rapid, moderate, slow, varied | attention, tension, cognitive load | Faster isn't automatically more engaging |
| **Tempo / speed** | rate of visual or sonic change | intensity, clarity | Separate speed from duration |
| **Pause / hold** | stillness or delay | processing time, emphasis | Holds should match content complexity |
| **Transition** | cut, fade, dissolve, wipe, morph, state change | continuity, hierarchy | Purposeful, not decorative |
| **Loop / frequency** | repetition over time | rhythm, persistence | Loops can fatigue or distract |
| **Easing** | linear, ease-in, ease-out, overshoot | naturalness, weight, emphasis | Respect reduced-motion settings |
| **Synchronisation** | aligned or offset events | audiovisual coherence, feedback | Don't make meaning depend on sync alone |

## Production and reproduction

| Process | Time risks |
|---|---|
| Video | Frame rate, platform length limits and compression constrain timing |
| Animation | Frame timing and render cost limit motion complexity |
| UI | Device performance and latency change intended transition timing |
| Exhibitions | Scheduling, dwell, reset time and accessibility shape timing |
| Social platforms | Autoplay without sound, loop behaviour and first-second hooks |

## Time and duration across fields

- **Branding:** a motion identity specifies logo animation, entry and exit durations, easing families, transition behaviour, sequencing and tempo, with reduced-motion and static equivalents.
- **Graphic and communication design:** mostly static, but time appears in sequence (multi-panel posters, carousels, slide decks) and in how long a viewer has to read (billboards, bus sides).
- **Video, film and animation:** shot duration, edit pacing, montage, continuity, frame timing, keyframes, holds, spacing, anticipation, easing. Motion graphics coordinate entrance, hold, transition and exit so text is readable before it goes.
- **UI / UX:** response time, feedback delay, loading states, microinteraction duration, progressive disclosure and timeouts. Users should be able to pause, stop or extend time; avoid auto-advancing essential content (WCAG 2.2.2).
- **Textiles and fashion:** less central to a static textile, but relevant to wear, transformation, responsive textiles, performance costumes and production sequence.
- **Product and industrial design:** interaction feedback, cycle times, maintenance intervals, staged use. Latency changes perceived quality and safety.
- **Interiors, exhibitions and architecture:** visitor sequence, dwell time, queues, timed media, daylight change and programmed installations.
- **Technical communication:** storyboards, animatics, timelines, cue sheets and state diagrams communicate timing; a static drawing can't show duration without notation.
