# Line: analysis and model answers

Use this file for analyses, annotations, exemplars and model answers about line in a specific design.

## Workflow

1. **Fix the artefact.** Work from the user's image or description. If you're inventing one for an exemplar, describe it briefly first so students can picture it, with the specific line characteristics the answers will cite.
2. **Work through the progression** (`method/analysis.md`): identify → describe → explain → analyse (connect to communication, purpose, audience) → evaluate against a named criterion, including a limitation or trade-off.
3. **For levelled exemplars** (e.g. developing / sound / high-range), make each level add a link in the reasoning chain, not just more words. Respect word limits. Under each, add a short note on what lifts it to the next level. The justification ladder in `feedback.md` shows the pattern.
4. **Go beyond the element on its own.** Use the relationships with other elements and principles in `knowledge.md`.
5. **Language** (`method/checks-and-language.md`): conditional wording for emotional or cultural readings, observation before interpretation, and no "it works" without a criterion.


## Worked analysis (model for exemplars and annotations)

The scenario is an A3 poster for a city fun run. Four white road-marking lines start wide at the bottom-left corner and taper as they converge on the event title in the upper right. The background is dark asphalt grey.

- **Identify (weak on its own):** "The poster uses line."
- **Describe:** "Four white lines run diagonally from the bottom-left corner and converge on the title in the upper right. They taper from about 8 mm wide to about 1 mm."
- **Explain:** "The convergence and taper create linear perspective, so the lines read as a road going into the distance. Because they point at the title, they lead the eye straight to it."
- **Analyse:** "The lines work with value contrast (white on dark grey) and scale (the title is the largest type) so the path and the focal point reinforce each other. The diagonal direction also suggests forward movement, which suits a running event."
- **Evaluate:** "This is effective for a poster seen briefly from a distance because the route to the title is immediate. However, the 1 mm tapered ends will likely break up if the artwork is reduced to a 1080 px social tile. Setting a heavier minimum stroke for the small version would protect the effect."

When writing exemplars at different levels, each level should add a link in the chain rather than simply using longer sentences.
