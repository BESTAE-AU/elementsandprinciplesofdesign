## Adobe creative workflow

Select software for the task and deliverable rather than popularity. A software application is a system component; its tools are specific functions, and techniques describe how they are applied.

## Application roles

| Application | Typical role | Example tool/technique categories |
|---|---|---|
| Photoshop | Raster editing and compositing | Selections, masks, adjustment layers, retouching |
| Illustrator | Vector graphics | Paths, shape construction, type, symbols |
| InDesign | Publication and page layout | Styles, frames, linked assets, tables, preflight |
| Premiere | Video editing and delivery | Trimming, sequences, captions, audio integration |
| After Effects | Compositing and motion graphics | Keyframes, masks, effects, layered animation |
| Animate | Animation and interactive asset workflows | Frame-by-frame, tweens, symbols and timelines |
| Acrobat | PDF inspection and document workflows | Page tools, forms, accessibility review |
| Express | Template-based communication assets | Layout adaptation, brand assets and export |
| Adobe Fonts | Typeface access and hosting | Family/style selection, language support, licensing |

These are broad roles, not promises of a particular menu or feature in every plan/version.

## Cross-application relationships

Create vector assets in Illustrator, refine images in Photoshop, assemble publications in InDesign and export the appropriate PDF. Create/edit footage in Premiere, develop motion/composites in After Effects and integrate rendered or linked assets according to the workflow.

Maintain organised originals, working projects, linked assets and outputs. Native files preserve editability; exports serve delivery. Moving or renaming linked assets can break projects. Package or collect assets using the relevant supported method and licence conditions.

## Non-destructive practice

Preserve originals and versions. Use masks and adjustment layers where suitable instead of permanently removing or altering data. Keep editable text where needed. Rasterising or outlining can aid a specific delivery but reduces later editability; preserve an editable master.

Use consistent names and document important changes. A mock-up demonstrates appearance in a context; it does not prove actual print quality, fit or material performance.

## Colour, fonts and export

RGB values do not guarantee identical appearance across devices. CMYK output depends on profile, process and substrate. Preserve relevant profiles and proof intended output. See [Adobe colour-management guidance](https://helpx.adobe.com/photoshop/using/color-managing-imported-images.html).

[Adobe Fonts licensing](https://helpx.adobe.com/fonts/web/font-licensing/font-licensing.html) distinguishes supported document/web uses from uses requiring other licences, including direct app embedding. Do not redistribute font files or assume a subscription grants every deployment right. Check current terms and the exact use.

For video, choose resolution, frame rate, codec, container, bitrate, colour and captions according to purpose and current delivery requirements. For print, verify page size, bleed, image detail, fonts and colour with the production provider. Avoid universal export presets.

## Teaching and evaluation

Teach a purposeful workflow: goal, asset preparation, demonstrated tool use, guided practice, export and inspection. Tool-list memorisation alone does not establish application. Ask students to justify why the software/tool/technique improves the project and what alternative was considered.

Support with a small tool set and reusable assets. Extend through integration, non-destructive revisions and comparative export testing. Evaluate the final exported file as well as the editable project.

Current documentation is authoritative for menus, supported formats and licensing. The collection does not invent current screenshots or exact UI steps.


## Additional workflow concepts

Lightroom-style workflows use organised image cataloguing and non-destructive adjustments. A catalogue or adjustment record is not the same as a self-contained copy of all photographs. Maintain access to originals and verify export quality.

Batch editing should create coherent treatment while preserving appropriate individual corrections. Social variations need purposeful crop, aspect ratio, safe placement and current delivery checks. A resize that cuts off the message is not successful adaptation.

Mock-ups can demonstrate a logo or design on packaging, garments, screens or spaces. Label them as visualisations when they do not show a manufactured result. Assess perspective, scale and context without claiming actual material performance.

Acrobat forms require usable labels, logical tab order and testing. A visible blank rectangle is not necessarily a functioning field. Exported PDFs need inspection for font issues, clipping, accessibility and correct version, not only successful file creation.
