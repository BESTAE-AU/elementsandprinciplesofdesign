# Multimedia Fundamentals

## Purpose and provenance

A reference knowledge base for Claude, covering concepts, relationships, application and teaching. This is not an installable skill.

Multimedia Teaching Assistant framework, shared design knowledge and general media fundamentals. Software capabilities must be verified through current Adobe documentation.

## Multimedia systems and communication

Multimedia combines media such as text, graphics, image, audio, video, animation and interaction. A system includes hardware, software, data, people and procedures; software alone is not the complete system. Tools are specific functions or equipment used within the system. A technique is a way of applying tools to achieve an effect.

**Audience → purpose → content → media selection → interaction/sequence → production → delivery → testing.**

More media does not automatically improve learning or communication. Select each medium for what it contributes; competing sound, motion and text can increase unnecessary demand.

## Technical distinctions

| Term | Meaning and implication |
|---|---|
| Resolution | Pixel dimensions or detail capacity; does not guarantee quality |
| Frame rate | Frames per second; affects motion representation and workflow |
| Aspect ratio | Width-to-height relationship, independent of pixel count |
| Codec | Method of encoding/decoding media |
| Container | File structure holding streams and metadata, such as MP4 or MOV |
| Bitrate | Data rate; influences file size and compression behaviour |
| Lossy compression | Discards information to reduce size |
| Lossless compression | Permits exact reconstruction of encoded data |
| Interactivity | User actions affect system state or experience |

Estimate file size from bitrate × duration, allowing for audio and container overhead. Reducing file size may compromise detail, motion or audio quality. Compare exports on target devices and actual delivery conditions.

## Analysis framework from the Multimedia Teaching Assistant

- Characteristics: observable appearance or sound.
- Features: capabilities and functionality.
- Properties: measurable or technical qualities.
- Attributes: audience, purpose, meaning and experience.

**Identify → describe → explain → analyse → apply → justify → evaluate.**

Example: a caption is a feature; text size is a property; its appearance is a characteristic; improved access to spoken information relates to an attribute and user experience. These lenses can overlap; explain the analytical role.

## Production and project management

Pre-production establishes brief, research, script, storyboard, shot list, asset permissions, equipment, schedule and testing requirements. Production captures or creates assets. Post-production assembles, edits, mixes, animates, corrects and exports. Evaluation occurs throughout.

Use sensible file naming, source/project/output separation, versions and backups. A project file usually references external assets; it is not automatically a self-contained deliverable.

## Teaching architecture

For structured teaching pages, the plugin uses title; overview; core content blocks; describing/analysing; resources; examination examples; project application; HSC-style questions; glossary. Core blocks include definition, importance, key ideas, guiding questions and meaningful media examples. This structure is a resource preference, not a requirement for every knowledge-base response.

Project justification covers selection, reason, improvement and alternatives. Questions should target taught content and the identified syllabus version. HSC-style does not mean an official past-paper question.

## Access and misconceptions

Provide captions/transcripts, essential visual alternatives, readable interfaces and usable navigation. Verify platform specifications rather than assume fixed limits. “Higher resolution always looks better” ignores capture quality, compression, device, viewing distance and delivery constraints.


## Detailed element-specific applications from the existing knowledge base

### Colour

#### Multimedia

Photography and cinematography use lighting, white balance, production design and grading. Animation and motion graphics require palette continuity across frames and display conditions. Colour transitions should not carry essential meaning without redundant cues.

##### Static versus time-based use

Claude must distinguish the appearance of colour in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Direction

#### Multimedia

Use subject movement, camera pan/tilt/tracking, gaze, screen direction, perspective lines, animated vectors, wipes, transitions and kinetic typography to build directional continuity. Screen direction changes can intentionally disorient or accidentally break continuity. Static frames and time-based sequences must be analysed separately.

##### Static versus time-based use

Claude must distinguish the appearance of direction in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Form

#### Multimedia

Photography and cinematography reveal form through light direction, lens, perspective, blocking and movement. 3D animation uses modelling, topology, materials, lighting and camera. Motion graphics may simulate depth, but Claude should distinguish genuine 3D form from flat shape animation with depth effects.

##### Static versus time-based use

Claude must distinguish the appearance of form in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Layout And Composition

#### Multimedia

Film composition includes framing, headroom, lead room, depth, blocking, focal points and multiple-subject balance. Motion graphics require composition over time: elements enter/exit, hierarchy shifts, and spatial continuity must be preserved across frames and aspect ratios.

##### Static versus time-based use

Claude must distinguish the appearance of layout and composition in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Line

#### Multimedia

In video and photography, actual architectural edges, roads, horizons, eye-lines and object alignments can lead attention. In motion graphics and animation, line can draw-on, trace, connect, reveal, mask, transform and create timing cues. Line weight and continuity can change over time; motion must preserve hierarchy and accessibility rather than becoming decoration that competes with content.

##### Static versus time-based use

Claude must distinguish the appearance of line in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Shape

#### Multimedia

Shape organises title cards, lower-thirds, masks, transitions, characters, props and environments. In photography and film, cropping and lighting can create dominant shapes. In motion, shapes can morph, reveal and become transition devices; preserve recognition during animation.

##### Static versus time-based use

Claude must distinguish the appearance of shape in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Size And Scale

#### Multimedia

Shot size changes subject scale within frame and therefore information emphasis. Motion graphics use scale changes for hierarchy and transitions. Animated scale should not substitute for meaningful hierarchy and may require reduced-motion alternatives.

##### Static versus time-based use

Claude must distinguish the appearance of size and scale in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Space

#### Multimedia

Photography and film use foreground/background depth, blocking, headroom, lead room and negative space. Animation stages subjects in depth and across time. Motion graphics need room for entrance/exit and changing hierarchy, especially across aspect ratios.

##### Static versus time-based use

Claude must distinguish the appearance of space in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Texture

#### Multimedia

Lighting angle reveals texture in photography and cinematography. 3D animation uses texture maps, normal/bump/displacement maps, shaders and material properties. Digital grain may support a visual language but can interfere with compression and legibility.

##### Static versus time-based use

Claude must distinguish the appearance of texture in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Time And Duration

#### Multimedia

Video and film use shot duration, edit pacing, montage, continuity and sequence length. Animation uses frame timing, keyframes, holds, spacing, anticipation and easing. Motion graphics coordinate entrance, hold, transition and exit so information is readable before it disappears.

##### Static versus time-based use

Claude must distinguish the appearance of time and duration in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Typography

#### Multimedia

Titles, lower thirds, captions, subtitles and kinetic type must account for safe areas, reading duration, motion, contrast and platform cropping. Kinetic typography should preserve verbal comprehension while adding temporal hierarchy.

##### Static versus time-based use

Claude must distinguish the appearance of typography in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.

### Value

#### Multimedia

Exposure, lighting, colour grade and set design create value structure in photography and film. Motion graphics need stable tonal hierarchy across transitions. High dynamic range or changing scenes can alter legibility of overlays.

##### Static versus time-based use

Claude must distinguish the appearance of value in a single frame from its behaviour across time. In time-based work, analyse **entry, change, continuity, sequencing, persistence and interaction** as appropriate.
