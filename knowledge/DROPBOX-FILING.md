# Dropbox filing of the ChatGPT knowledge collection

Trimmed copies of the ChatGPT topic files and GPT instructions, filed into "Claude Knowledge" folders in Dropbox on 1 October 2026. Every file is new; nothing existing in Dropbox was changed. The prepared files are in `knowledge/dropbox-filing/`, at the same paths as in Dropbox (the Dropbox copies have a few extra pointer notes in their headers).

Multimedia files follow the naming convention in `/Teaching/Multimedia/Claude Knowledge/README - Naming Convention.md`, and the new folders use the same pattern. Files ending `-ChatGPTSynthesis` or `-ChatGPTInstructions` mark ChatGPT-origin material; where a Claude skill covers the same ground, the skill is the current version.

Not filed on purpose: topic 03 (elements master, 407 KB) and 04 (principles master), which the skills already contain, and the 934 KB all-topics file. None of these should be used as project knowledge.
