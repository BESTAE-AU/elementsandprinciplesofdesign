Reference copies of the MCCNS logo, taken directly from page 2 of the 2020 Visual Identity Guidelines at 400 dpi. They are not redrawn.
- `mccns-logo-vertical.png`: standard vertical logo on white.
- `mccns-logo-horizontal-on-light-blue.png`: standard horizontal logo on `mcc-light-blue`, as shown in the guideline.
- `mccns-crest.png`: the crest only, on white.

Use them for drafts and on-screen previews. For print, and for the reversed and mono versions, use the official `.eps` files named in the guideline. Never recolour, crop into, stretch or redraw the logo.
