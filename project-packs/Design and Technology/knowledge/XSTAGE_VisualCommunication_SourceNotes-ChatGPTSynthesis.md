# Visual communication

## Communication as an intentional system

Visual communication uses images, symbols, type, colour, space and sequence to convey information, identity or meaning. Graphic design organises those resources for a purpose. Visual literacy concerns interpreting and creating meaning; information design concerns making information understandable and usable.

**Purpose → audience → message → medium → visual decisions → interpretation → action → evaluation.**

Define what an audience should know, feel or do before selecting a visual style. Audience involves prior knowledge, language, cultural context, viewing device, distance, available time and accessibility needs. A campaign may require multiple outputs with related identity but different hierarchy and detail.

## Core practices

| Practice | Main decision |
|---|---|
| Poster/advertising | Primary message and recognition under limited attention |
| Editorial/publication | Navigation, sustained reading and image/text relationships |
| Packaging | Recognition, information, handling and production constraints |
| Signage/wayfinding | Orientation, consistent naming, placement and visibility |
| Infographics | Accurate encoding, comparison and explanatory structure |
| Icons/symbols | Familiarity, ambiguity, labels and contextual interpretation |
| Environmental graphics | Scale, material, lighting, position and access |
| Cross-platform campaigns | Consistent meaning with adapted composition |

Hierarchy establishes order of attention. Proximity groups related information; alignment creates structure; contrast differentiates roles. Negative space separates and clarifies. Decorative devices should serve communication rather than compete with it.

An image can illustrate, explain, document, persuade or symbolise. Text may anchor interpretation, supply context or intentionally challenge the image. Analyse the relationship rather than discussing each independently. Gestalt tendencies such as similarity, proximity, continuity and figure–ground help explain grouping, but audience testing remains necessary.

## Information and ethical representation

Charts should use appropriate scales, units, labels and denominators. Avoid visually exaggerating differences, hiding uncertainty or using unrelated decorative area to imply quantity. Distinguish sourced evidence from illustrative data.

Symbols and colour meanings vary across communities. Avoid universal emotional claims. Credit creators and respect permissions. Cultural motifs require contextual knowledge and relevant authority, not just online availability.

## Accessibility and production

Use readable text, sufficient contrast, logical reading order, labels alongside colour and alternatives for essential images. Evaluate at final size and under realistic viewing conditions. Web text contrast guidance is in [W3C SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html); it does not by itself establish accessible print or complete web conformance.

Choose raster or vector according to content and reproduction. Proof fine lines, small type, image resolution, cropping, bleed and colour conversion with the intended production workflow.

## Analysis and teaching

**Observed variable → perceptual effect → meaning/function → audience/context → suitability.**

Weak: “The title is big.” Strong: “The title's size and value contrast establish first attention, enabling the main message to be recognised before supporting details during a brief viewing.” Verify this with quick-recognition testing rather than assuming success.

Teach through comparing two versions with one controlled change. Support with annotated examples and vocabulary. Extend through conflicting communication goals, responsive systems and research-informed interpretation. Assess message clarity and appropriateness alongside visual craft.
