# Value — element of design

This skill gives Claude the value-specific knowledge for teaching, analysing and designing with value (tone). The shared method — analysis progression, justification levels, Factors Affecting Design, experimentation, differentiation, feedback approach and language rules — is in the shared method files. Read the relevant section of that file when a task calls for it.

For calculating WCAG contrast ratios or auditing a whole palette, use the `colour-contrast-audit` skill if it's available; this skill covers what value does and why.

The core habit: look at value separately from hue. Move from **how light or dark things are, and how different** → **effect** (separation, hierarchy, depth, mood) → **why that matters here** → **how well it works and what it costs**.

## What value is

Value is the relative lightness or darkness of a colour, surface, image or element. Value relationships create separation, hierarchy, depth, modelling and tonal structure independently of hue.

Keep it distinct from its neighbours:
- **Value vs hue:** hue is the colour family; two different hues can share the same value.
- **Value vs saturation:** saturation is how colourful something is, not how light.
- **Value vs contrast:** contrast is a relationship; value contrast is one kind (hue, size and texture contrast are others).
- **Value vs lighting:** lighting changes perceived value, but they are different ideas.
- **Value ≠ monetary value** — say "tonal value" if there's ambiguity.

## Variables

| Variable | Range | Typical effect | Watch for |
|---|---|---|---|
| **Value level** | light, middle, dark | prominence, separation, mood | Interpret in context |
| **Value range** | narrow ↔ broad | detail, tonal differentiation | Narrow range can hurt readability |
| **Value contrast** | low ↔ high | figure-ground separation, hierarchy | Check text and control contrast |
| **Tonal grouping** | clusters of similar values | simplifies composition | Great for squint and greyscale tests |
| **Value pattern** | distribution of light and dark masses | compositional structure | Evaluate with thumbnails or blur |
| **Highlights, mid-tones, shadows** | tonal zones | model form and depth | Preserve detail for the medium |
| **Key** | high-key (mostly light), low-key (mostly dark) | overall tonal character | Avoid fixed emotional claims |
| **Opacity / blending** | transparent overlays | changes perceived contrast | Test on the real background |

## Types

- **Light, middle, dark value** — broad categories; all visual media.
- **High-key** — dominated by light values; photography, film, branding.
- **Low-key** — dominated by dark values; photography, film, dark-mode UI.
- **Monochrome / greyscale** — value without hue; testing and stylistic use.
- **Tonal modelling** — value transitions that describe form; illustration, photography, rendering.
- **Atmospheric value** — lighter, lower-contrast values with distance; landscape, film, spatial visualisation.

## How value works with the other elements

- **Line:** a line is only visible through value contrast with its ground; hatching density creates tone.
- **Direction:** a light-to-dark gradient creates a reading direction; the brightest point often ends the eye's path.
- **Shape:** value contrast is usually what separates a shape from its background.
- **Form:** highlight, mid-tone, core shadow, reflected light and cast shadow imply 3D form.
- **Space:** atmospheric perspective — distant things lighter and lower in contrast — builds depth.
- **Size and scale:** small elements (thin text, icons) need more value contrast than large ones.
- **Colour:** every colour has a value; palettes that look varied in hue can collapse in greyscale if the values match.
- **Texture:** texture is revealed by light and shadow on a surface; flat lighting flattens texture.
- **Typography:** text-to-background value contrast is the main driver of legibility.
- **Layout and composition:** the overall value pattern (where the big light and dark masses fall) structures the whole design before detail is seen.
- **Time and duration:** fades to black or white, lighting changes, and overlays moving over changing footage.

## How value contributes to the principles

- **Contrast:** value contrast is the strongest and most reliable contrast.
- **Emphasis:** the lightest light against the darkest dark usually becomes the focal point.
- **Hierarchy:** stepped values (dark headline, mid-grey body, light captions) rank information.
- **Balance:** dark masses feel heavier; a small dark area can balance a large light one.
- **Unity:** a limited tonal range ties an image or brand together.
- **Movement:** gradients and value paths move the eye.
- **Rhythm:** alternating light and dark bands.
- **Harmony:** close values feel calm and cohesive; big jumps feel dramatic — in context.

## Value across fields

- **Branding:** test brand palettes for value, not just hue. Monochrome logo testing shows whether shape and hierarchy survive without colour. Define dark and light background versions, reversal rules and accessible text pairings.
- **Graphic and communication design:** value contrast drives legibility, grouping and focal points in posters, publications and infographics. A squint or greyscale test shows the real hierarchy.
- **Photography, film and animation:** exposure, lighting ratio, colour grading and set design create value structure. Overlaid text and graphics need stable contrast across changing footage.
- **UI / UX:** value contrast governs text, icons, focus states and component separation. Avoid faint dividers; test light and dark modes and disabled states.
- **Textiles and fashion:** value comes from fibre colour, print, weave, pile direction, sheen and layering; it shifts with drape and light.
- **Product and industrial design:** material colour, gloss and lighting change perceived value; markings must stay distinguishable in real lighting.
- **Interiors and architecture:** surface reflectance, lighting and shadow create value patterns that affect atmosphere, wayfinding (e.g. contrasting stair nosings) and visual comfort.
- **Technical communication:** diagrams that may be printed in greyscale need clear tonal steps; subtle grey differences shouldn't be the only way categories are told apart.

## Production and reproduction

| Process | Value risks |
|---|---|
| Print | Dot gain, stock colour and ink limits compress tonal range; shadows block up |
| Screen | Brightness, ambient light and calibration change perceived value |
| Photography / video | Exposure and compression clip highlights and crush shadows |
| Textiles | Dye, fibre lustre and print penetration change apparent value |
| Greyscale / photocopy | Colours of similar value become indistinguishable |

## Common misconceptions

| Misconception | Better understanding |
|---|---|
| "Different colours always have different values." | Distinct hues can share lightness. Use a greyscale test. |
| "Bright colours are high contrast." | Saturation isn't value; a bright yellow on white has poor value contrast. |
| "Dark = serious, light = happy." | Associations depend on context. Describe the value structure first. |
| "Shading is just making things darker." | Modelling needs a full range: highlight, mid-tone, core shadow, cast shadow. |
| "It looks fine on my screen." | Screens vary; print and projection compress tone. Test the real output. |

## Worked analysis (model for exemplars and annotations)

Scenario: a low-key product photo for a candle brand. The background is near-black; the candle is lit from the left by its own flame and a small side light; the brand name sits in pale cream text in the lower right.

- **Identify:** "The photo uses value."
- **Describe:** "Most of the frame is very dark; the brightest values are the flame and the lit left side of the candle; the right side falls into shadow; the cream text is the second-lightest area."
- **Explain:** "Because almost everything is dark, the small bright flame becomes the focal point, and the gradient across the candle shows it's a rounded form."
- **Analyse:** "Value works with form and emphasis: the light-to-shadow transition models the cylinder, and the low-key range leaves only two light areas — flame then text — so the eye moves from product to brand name. The narrow bright range may suggest warmth and intimacy in this context."
- **Evaluate:** "Effective for a premium website hero image. However, the dark shadows may block up and lose the candle's texture when printed on uncoated stock for flyers; a print-adjusted version with lifted shadows should be proofed."

Each level should add a link in the chain, not simply more words.

## Justification examples (Year 9 poster)

- **Weak:** "I used a dark background because it looks dramatic."
- **Developing:** "I used a dark background with white text so the words stand out."
- **Strong:** "I used a near-black background with white headline text, giving very high value contrast, so the headline is readable from across the canteen. That suits a noticeboard poster that students pass quickly."
- **Sophisticated:** "I printed the poster in colour and in greyscale. In greyscale the orange subheading and red date merged into the same mid-grey, so I lightened the orange to create a clear value step. The headline's white-on-black contrast worked in both. The orange is now less saturated than I wanted, but the hierarchy survives photocopying, which the school office uses."

## Feedback patterns to look for in student work

- **Hierarchy collapses in greyscale** — colours of the same value.
- **Low-contrast text** (grey on grey, pastel on white, text over busy photos).
- **Flat shading** — only one or two values, so form doesn't read.
- **Mood stated as fact** ("dark means sad") without context.
- **Value confused with saturation** in written analysis.
- **Dark print areas** with no allowance for dot gain.

## Activity ideas for teaching resources

- **Value scale:** paint or hatch a 9-step scale; match colour chips to it.
- **Greyscale test:** convert a poster to greyscale; does the hierarchy survive?
- **Squint and blur:** blur three layouts and identify the main light and dark masses.
- **Light a sphere:** photograph a ball with one light from different angles; label highlight, core shadow and cast shadow.
- **High-key vs low-key (Multimedia):** shoot the same subject both ways and compare.
- **Contrast fix (UI):** find a low-contrast website and redesign one component to improve value contrast.
