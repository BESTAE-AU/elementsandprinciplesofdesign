# Visual communication

Use this guide for posters, advertising, editorial, packaging, signage, infographics, icons and campaigns: any task about how a design communicates a message to an audience.

**Chain:** purpose → audience → message → medium → visual decisions → interpretation → action → evaluation.

Decide what the audience should know, feel or do before choosing a style. Audience includes prior knowledge, language, culture, device, viewing distance, time available and access needs. A campaign may need several outputs with a shared identity but different hierarchy and detail.

## Practices and their main decision

| Practice | Main decision |
|---|---|
| Poster / advertising | The primary message, recognised under limited attention |
| Editorial / publication | Navigation, sustained reading, image–text relationships |
| Packaging | Recognition, information, handling, production limits |
| Signage / wayfinding | Orientation, consistent naming, placement, visibility |
| Infographics | Accurate encoding, comparison, explanatory structure |
| Icons / symbols | Familiarity, ambiguity, labels, context |
| Environmental graphics | Scale, material, lighting, position, access |
| Cross-platform campaigns | Consistent meaning with adapted composition |

## Key ideas

- Hierarchy sets the order of attention; proximity groups; alignment structures; contrast differentiates roles; negative space separates and clarifies. Decoration should serve communication, not compete with it.
- An image can illustrate, explain, document, persuade or symbolise. Text can anchor the image's meaning, add context or deliberately challenge it. Analyse the image–text relationship, not each part separately.
- Gestalt tendencies (similarity, proximity, continuity, figure–ground) explain grouping, but audience testing is still needed.

## Honest information and representation

- Charts need appropriate scales, units, labels and denominators. Don't exaggerate differences, hide uncertainty or use decorative area to imply quantity. Separate sourced data from illustrative data.
- Symbol and colour meanings vary between communities, so avoid universal emotional claims. Credit creators and respect permissions. Cultural motifs need contextual knowledge and the relevant authority, not just online availability.

## Accessibility and production

Readable text, enough contrast, logical reading order, labels as well as colour, and alternatives for essential images. Evaluate at final size and in realistic viewing conditions. WCAG text contrast (SC 1.4.3) applies to web text and doesn't by itself make print accessible. Choose raster or vector by content and reproduction; proof fine lines, small type, resolution, cropping, bleed and colour conversion in the real workflow.

## Analysis and teaching

**Observed variable → perceptual effect → meaning or function → audience and context → suitability.**

- Weak: "The title is big."
- Strong: "The title's size and value contrast make it the first point of attention, so the main message is recognised before the supporting details in a brief viewing." Check this with a quick-recognition test rather than assuming it.

Teach by comparing two versions with one controlled change. Support with annotated examples and vocabulary; extend with conflicting goals, responsive systems and research-informed interpretation. Assess message clarity and appropriateness alongside craft.
