# Harmony — principle of design

This skill covers **harmony** as a principle of design. Principles describe relationships and organisational effects; elements (line, direction, shape, form, space, size and scale, time and duration, value, colour, texture, typography, layout and composition) are the variables that create them. So always explain *which elements* produce harmony and *how*, and never treat an element and a principle as the same thing.

The shared method (analysis progression, justification levels, Factors Affecting Design, experimentation, teaching resources, feedback and marking, and language rules) is in the shared method files. For depth on a particular element, use its `<element>-element-of-design` skill. For whole-process help, use the method skills (`design-analysis-progression`, `design-justification-writing`, `design-feedback-and-marking`, and so on).

## What harmony is

Harmony is the pleasing relationship between elements that share qualities, such as related colours, similar shapes, compatible type or materials, so they feel like they belong together.

Keep it distinct:
- **Harmony vs unity:** harmony is about compatibility of elements; unity is whether the whole holds together.
- **Harmony vs sameness:** harmonious elements are related, not identical.
- **Harmony vs contrast:** contrast highlights difference; harmony emphasises shared qualities. Most designs balance both.

## Types and variations

- **Colour harmony:** analogous, monochromatic, or controlled complementary schemes.
- **Shape harmony:** shared geometry or corner logic.
- **Typographic harmony:** type pairings with compatible proportions.
- **Material harmony:** textures and finishes that suit each other.
- **Deliberate discord:** clashing on purpose for effect.

## Levers: what a designer changes to create harmony

- Related hues and values
- Shared geometry
- Compatible type
- Related textures and materials
- Consistent style

## Common misconceptions

| Misconception | Better understanding |
|---|---|
| "Harmony means using matching colours only." | It applies to shape, type, texture and materials too. |
| "Clashing is always wrong." | Deliberate discord can suit some briefs. |
| "Harmony is subjective, so can't be analysed." | Name the shared qualities that create it. |

## Worked analysis (model for exemplars and annotations)

Scenario: A skincare package: soft sage green, warm cream and matte paper stock, with rounded shapes and a humanist sans-serif.

- **Identify:** "The design uses harmony."
- **Describe:** "Analogous muted colours, matte texture, rounded shapes and a typeface with soft curves."
- **Explain:** "Colour, shape, texture and type share softness, so the package feels harmonious."
- **Analyse:** "Harmony comes from consistent qualities across elements; a small darker accent adds just enough contrast to keep it from being bland."
- **Evaluate:** "Effective for a gentle skincare brand. However, the sage text on cream has low value contrast for ingredient lists; darker text would keep harmony while improving readability."

Each level should add a link in the chain, not simply more words.

## Justification examples

- **Weak:** "I chose things that go together."
- **Developing:** "I used soft colours and rounded shapes so it matches."
- **Strong:** "I used muted greens, matte stock, rounded shapes and a humanist sans so every element shares a soft quality that suits a gentle skincare brand."
- **Sophisticated:** "I tried a geometric sans that clashed with the rounded shapes. The humanist sans matched the curves but was harder to read small, so I used it only for headings and a clearer sans for ingredients."

## Feedback patterns to look for in student work

- **'It goes together'** with no shared quality named.
- **Harmony with no contrast** (bland).
- **Clash not deliberate.**
- **Material and texture ignored.**

## Activity ideas for teaching resources

- **Find the shared quality:** list what makes three elements harmonious.
- **Clash on purpose:** design a deliberately discordant poster and explain the effect.
- **Material board:** assemble harmonious samples for a brief.
- **Type pairing test:** pair a heading font with three body fonts and discuss.
