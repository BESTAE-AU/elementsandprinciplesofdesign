# Variety — principle of design

This skill covers **variety** as a principle of design. Principles describe relationships and organisational effects; elements (line, direction, shape, form, space, size and scale, time and duration, value, colour, texture, typography, layout and composition) are the variables that create them. So always explain *which elements* produce variety and *how*, and never treat an element and a principle as the same thing.

The shared method (analysis progression, justification levels, Factors Affecting Design, experimentation, teaching resources, feedback and marking, and language rules) is in the shared method files. For depth on a particular element, use its `<element>-element-of-design` skill. For whole-process help, use the method skills (`design-analysis-progression`, `design-justification-writing`, `design-feedback-and-marking`, and so on).

## What variety is

Variety is the use of different elements or treatments to create visual interest and prevent monotony, while keeping the design unified.

Keep it distinct:
- **Variety vs contrast:** variety is having differences; contrast is how strong they are.
- **Variety vs chaos:** variety works within a system; chaos has no controlling logic.
- **Variety vs unity:** they are paired; most designs need both.

## Types and variations

- **Size variety.**
- **Colour variety.**
- **Shape and texture variety.**
- **Typographic variety** (within one or two families).
- **Pacing variety** in time-based media.
- **Layout variety** within a grid.

## Levers: what a designer changes to create variety

- Varied scale
- Accent colours
- Contrasting shapes and textures
- Type weights
- Shot lengths and pacing
- Layout variations

## Common misconceptions

| Misconception | Better understanding |
|---|---|
| "More variety is more interesting." | Unchecked variety becomes chaos. |
| "Variety breaks consistency." | Variety within rules keeps consistency. |
| "Variety is decoration." | It can signal differences in content or function. |

## Worked analysis (model for exemplars and annotations)

Scenario: A photo-essay website: all images sit on a 12-column grid, but spans vary between 4, 6 and 12 columns, and one full-bleed image appears every five sections.

- **Identify:** "The design uses variety."
- **Describe:** "Consistent grid with varied image spans and a periodic full-bleed image."
- **Explain:** "Varying spans keeps scrolling interesting; the full-bleed image marks key moments."
- **Analyse:** "Variety is controlled by the grid (unity) and used to signal importance (hierarchy), not randomly."
- **Evaluate:** "Effective for a long read. However, on mobile all spans collapse to full width, losing variety; alternating image crops or captions could keep interest on small screens."

Each level should add a link in the chain, not simply more words.

## Justification examples

- **Weak:** "I added variety so it's not boring."
- **Developing:** "I used different image sizes to make it interesting."
- **Strong:** "I varied image spans within one grid and used a full-bleed image for key moments, so scrolling stays interesting and the most important images stand out."
- **Sophisticated:** "On mobile the spans collapsed and testers found it repetitive, so I alternated tall and wide crops for small screens. The mobile layout is less dramatic than desktop but keeps the variety."

## Feedback patterns to look for in student work

- **Monotony** — every element identical.
- **Chaos** — variety without a system.
- **Variety with no purpose** or meaning.
- **Too many typefaces** used for 'variety'.

## Activity ideas for teaching resources

- **Monotony fix:** add variety to a repetitive layout using one change only.
- **Chaos fix:** bring order to an over-varied design with one rule.
- **Pacing edit:** vary shot lengths in a clip and compare.
- **Spot the system:** identify the rules behind variety in a magazine.
