# Elements and principles of design

Claude skills for teaching and applying the elements and principles of design in NSW Stage 4–6 design subjects (Visual Arts / Visual Design, Graphics Technology, Multimedia, Textiles, Timber, D&T).

Each skill lives in `skills/<skill-name>/` with a `SKILL.md`, `references/` and, where useful, a standard-library Python script in `scripts/`.

## Skills

| Skill | Element / principle | What it does |
|---|---|---|
| [`texture-element-of-design`](skills/texture-element-of-design/SKILL.md) | Texture | Explains actual vs visual and simulated vs invented texture; analyses texture in artworks, posters, products and textiles; plans lessons and activities; gives tool-specific steps for adding texture (Adobe, Canva, Photoshop, print finishes). Script: worst-case contrast for text over texture with a scrim fix, and an A4 mark-making worksheet generator |

Colour and typography are covered by the existing `colour-*` and `typography-*` skills.
