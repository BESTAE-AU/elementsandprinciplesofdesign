# Elements and principles of design

Claude skills for teaching, analysing and applying the elements and principles of design (NSW Stage 4–6 Visual Arts, Visual Design, Graphics Technology, Multimedia, Photographic and Digital Media, Textiles, D&T).

Each skill is a folder with a `SKILL.md` and optional `references/`. To install one, upload its folder as a skill in Claude.

## Elements

| Skill | Covers |
|---|---|
| [`direction/`](direction/SKILL.md) | Horizontal, vertical, diagonal, curved and radial direction; actual vs implied direction; eye path and reading patterns (Z, F, Gutenberg); lead room; links to movement, rhythm, emphasis and balance; analysis, critique, model annotations and teaching activities |
