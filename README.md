# Elements and Principles of Design

A Claude Code skill suite for teaching, analysing, generating, justifying, evaluating and refining the **Elements of Design**. It draws on NSW TAS design decision-making, multimedia analysis, Visual Arts, inclusive education, assessment, and Canva and Adobe design/typography guidance.

## Skills

Each skill is a self-contained `SKILL.md` in `.claude/skills/`, so Claude Code loads them automatically when working in this repository.

## Using the skills elsewhere

- **Claude Code (another project or globally):** copy a skill folder into that project's `.claude/skills/` or into `~/.claude/skills/`.
- **Claude.ai:** zip a single skill folder (e.g. `element-of-design-colour/`) and upload it under *Settings → Capabilities → Skills*.
